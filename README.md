# 🌀 My-Head

Site simples e divertido com GIFs de uma cabeça girando fofa.

![Cabeça girando](img/imgLegal.gif)

## 📌 Sobre

Projeto desenvolvido para praticar HTML, CSS, Bootstrap e GSAP, com foco em fluxo de versionamento usando GitFlow (branches, commits, Pull Requests e deploy via GitHub Pages).

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- [Bootstrap 5](https://getbootstrap.com/)
- [GSAP](https://gsap.com/)

## 🚀 Como visualizar

Você pode acessar o site publicado em:

🔗 [https://usuario.github.io/My-Head/](https://usuario.github.io/My-Head/)

Ou rodar localmente:

1. Clone o repositório
```bash
   git clone https://github.com/usuario/My-Head.git
```
2. Abra o arquivo `index.html` no navegador
